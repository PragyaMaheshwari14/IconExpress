# Icon Express

**Icon Express** is a powerful and user-friendly logo maker designed for seamless icon customization. Users can effortlessly modify icons by adjusting size, rotation, background color, and icon color, ensuring complete creative flexibility. Built with **React and Vite**, the platform provides a real-time preview experience with high-quality PNG exports.

## 📌 Key Features

- **Effortless Icon Customization** – Modify icons with ease by adjusting size, rotation, background, and icon colors.
- **Real-Time Editing** – Instantly preview changes for a smooth design process.
- **High-Resolution PNG Export** – Download refined icons in professional-grade resolution.
- **Modern UI & Performance** – Developed using **React, Vite, Tailwind CSS, and ShadCN** to ensure a responsive and optimized experience.

---

## 🛠 Technology Stack

- **Frontend:** React, Vite, Tailwind CSS, ShadCN
- **Build Tool:** Vite for fast development and optimized performance

## 📥 Installation Guide

Follow these steps to install and run the project on your local machine:

### **1️⃣ Clone the Repository**

```bash
git clone https://github.com/your-username/icon-express.git
cd icon-express
```

### **2️⃣ Install Dependencies**

```bash
npm install
```

### **3️⃣ Start the Development Server**

```bash
npm run dev
```

The application will be available at `http://localhost:5173/` (default Vite port).
